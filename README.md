# Parallax

Download the latest macOS build:

**[Parallax for Apple Silicon (.dmg)](https://github.com/ZaphodBeblerbox/parallax-releases/releases/latest/download/Parallax_1.0.0_aarch64.dmg)**

Open the `.dmg` and drag Parallax to Applications.

### The first launch will warn you

The app is not signed with an Apple Developer certificate, so macOS says it
cannot verify the developer. To open it:

1. Right-click Parallax in Applications and choose **Open**
2. Click **Open** again in the dialog

You only need to do this once. If the dialog gives you no Open option, go to
**System Settings > Privacy & Security**, scroll to the message about
Parallax, and click **Open Anyway**.
